# 铁板神数 - 先天考刻推演系统

> 铁板神数是中国古代命理预测的重要方法之一，本系统实现了完整的铁板神数算法，包括先天命数计算、考刻定刻、六亲考刻、流年推演等功能。

> ✨ **v3.0 起已支持纯前端运行**：全部算法（含农历/八字换算）已移植为浏览器端 JavaScript，无需 Python 后端，可直接部署到 Cloudflare Pages 等静态托管平台。Python 版本作为原始实现保留（见下方「本地开发」）。

## 功能特性

- 🎯 **先天命数计算** - 基于出生年月日时自动计算先天命数
- ⏰ **八刻细分功能** - 精确到刻(15分钟)的考刻定刻
- �‍👩‍👧‍👦 **六亲考刻验证** - 通过已知六亲信息（父母、兄弟、妻财、官鬼、子孙）验证刻别
- � **本命条文推演** - 计算本命条文及对应的断语
- 📅 **流年预测** - 提供1-108岁完整流年数据
- 🎨 **精美界面** - 传统风格的现代化Web界面
- 🔢 **铁板核心公式** - 终局条文数 = 本命基数 + 刻干数 × 48
- 🖨️ **打印支持** - 完整的打印报告功能

## 算法核心

### 1. 八刻细分
将一个时辰(2小时)细分为八刻：
| 刻别 | 分钟范围 | 天干 | 刻干数 |
|-----|---------|------|--------|
| 初刻 | 0-15分   | 甲 | 1 |
| 一刻 | 15-30分  | 乙 | 2 |
| 二刻 | 30-45分  | 丙 | 3 |
| 三刻 | 45-60分  | 丁 | 4 |
| 四刻 | 60-75分  | 戊 | 5 |
| 五刻 | 75-90分  | 己 | 6 |
| 六刻 | 90-105分 | 庚 | 7 |
| 正刻 | 105-120分| 辛 | 8 |

### 2. 铁板核心公式
```
终局条文数 = 本命基数 + 刻干数 × 48
```

### 3. 六亲考刻
通过已知六亲信息验证刻别的准确性：
- **父母**：父母生肖、寿命、职业等描述
- **兄弟**：兄弟数量、富贵程度等
- **妻财**：姻缘、财富、配偶情况等
- **官鬼**：功名、仕途、灾祸、疾病等
- **子孙**：子女数量、贤孝程度等

系统会自动计算每个可能刻别的匹配度，推荐最符合已知信息的刻别。

## 快速开始

### 方法一：部署到 Cloudflare Pages（推荐，纯前端）

1. 打包以下文件（保持目录结构）：`index.html`、`result.html`、`Print.html`、`js/lunar.js`、`js/db-data.js`、`js/tieban.js`。
2. 在 Cloudflare Pages 新建项目 → 选择「直接上传（Direct Upload）」→ 拖入上述文件（或压缩包）。
3. 无需构建命令、无需环境变量，部署完成即可访问。

> 同样适用于 GitHub Pages、Vercel、Netlify 等任意静态托管，或本地直接用浏览器打开 `index.html`。

### 方法二：本地开发（Python 原始实现）

Python 版本保留用于对照/调试，运行方式：

1. **安装依赖**：`pip install -r requirements.txt`
2. **启动服务器**：`python server.py`（或 Windows 双击 `启动.bat`）
3. **访问系统**：打开浏览器访问 `http://127.0.0.1:8000`

> 注：前端页面默认走纯前端计算（`js/tieban.js`），已不再依赖 `/api/calculate` 后端接口。

## 使用说明

### 输入信息

#### 基本信息
- **性别**：选择男或女
- **出生时间**：格式为 `YYYY-MM-DD HH:MM`（如：1990-05-15 14:30）
- **求测时间**：格式同上，默认为当前时间

#### 六亲考刻信息（可选）
如果您知道以下六亲信息，可以填写以验证刻别：
- **父母**：如"属马"、"长寿"、"先去父"等
- **兄弟**：如"二人"、"兄弟富贵"等
- **妻财**：如"美貌"、"富有"、"姻缘早定"等
- **官鬼**：如"做官"、"有灾"、"功名迟"等
- **子孙**：如"贤孝"、"多子"、"二子贵"等

### 输出内容

系统将展示：

1. **基本信息** - 八字、命卦、命数、刻别等
2. **本命条文** - 本命对应的条文、断语及铁板公式计算结果
3. **六亲考刻分析** - 六亲条文分析、刻别验证结果
4. **流年预测** - 1-108岁的完整流年数据（分为1-30、31-60、61-90、91-108岁四个标签页）
5. **打印支持** - 点击打印按钮可生成完整打印报告
