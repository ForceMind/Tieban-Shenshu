# 使用手册

面向使用者：如何排盘、如何看懂结果。

## 一、开始排盘

打开首页 `index.html`，填写：

- **性别**：男 / 女
- **出生时间**：公历，精确到分钟（分钟会影响「刻别」，请尽量准确）
- **求测时间**：公历，默认当前时间（影响日命/时运的取数）

点击「开始推演」，稍候片刻跳转到结果页。

> 纯前端运行，数据只保存在你本机浏览器（localStorage），不上传服务器。

## 二、结果页解读

### 1. 输入信息
回显性别、出生/求测公历时间、农历、是否闰月、两个八字（年月日时四柱）。

### 2. 基础排盘
| 项 | 含义 |
|---|---|
| 先天命数 | 由农历月与出生时辰推得（1~12） |
| 五音命数 | 宫商角徵羽对应数 |
| 日命数 / 时运数 | 由纳音五行查表所得 |
| 刻别 | 出生分钟所在的八刻（初刻…正刻） |
| 本命数 | 核心中间量，决定卦名与流年 |
| 十二辟卦 | 本命卦名 |
| 后天命数 | (先天命数+本命数) 除 8 的余数 |
| 三元九运 | 出生年所属元期 |
| 五数寄宫 | 后天命数为 5 时的寄宫处理 |
| 八卦加则 | 卦对应的起始数与口诀 |

### 3. 卦象
显示本命卦的上卦、下卦与组合。

### 4. 本命条文
按「性格 / 才能前程 / 财运 / 兄弟个数」列出条文数、计算式与断语。断语下方附**现代白话**。

### 5. 流年推演（1~108 岁）
顶部按 1-30 / 31-60 / 61-90 / 91-108 岁分段切换。每岁一张**卡片**，默认显示：

- **岁数 / 公历年**：虚岁，下方标注对应公历年份（虚岁 1 岁 = 出生当年）。
- **干支**与**主断语**（默认取校正后条文断语）。

**点击卡片展开**可看该岁全部细节：原条文 / 校正后条文 / 铁板公式三组的条文数、断语、现代白话，以及五音 / 标记 / 字母 / 校正数 / 八卦加则等标签。其中「校正后条文」被标为**主判读**并高亮。

## 三、三种断语看哪个？

| 断语 | 是什么 | 建议 |
|---|---|---|
| 原条文 | 最原始查得的条文断语 | 参考 |
| 校正后条文 | 按年龄校正后的条文断语 | **一般以此为准** |
| 铁板公式 | 原条文数 + 刻干数×48 的断语 | 本系统「终局」口径，作对照 |

> 具体以哪个为主，取决于你所依循的铁板流派判读习惯。

## 四、现代白话

三种断语及本命条文断语的**下方绿色小字**为文言断语的现代白话释义，帮助不熟悉文言者快速理解大意。白话为辅助参考，原文言仍为准。

## 五、打印

结果页点击打印按钮打开打印版（`Print.html`，1-100 岁单表），可直接浏览器打印或另存 PDF。

## 六、常见问题

- **出生分钟不确定？** 刻别按 15 分钟一刻划分，分钟误差可能改变刻别，进而影响刻干数与条文，尽量填准。
- **换了浏览器/清了缓存看不到上次结果？** 结果存于本机 localStorage，换设备或清缓存即丢失，重新排盘即可。
