# 使用手册

面向使用者：如何排盘、如何看懂结果。界面为浅色「纸墨」风格，移动优先。

## 一、开始排盘

打开首页 `index.html`，填写：

- **性别**：男 / 女
- **出生时间**：公历，精确到分钟（分钟会影响「刻别」，请尽量准确）
- **求测时间**：公历，默认当前时间（影响日命/时运的取数）

点击「开始推演」，稍候片刻跳转到结果页。

> 纯前端运行，数据只保存在你本机浏览器（localStorage），不上传服务器。

## 二、结果页解读

页面顶部有**吸顶导航**（概览 / 排盘 / 本命 / 流年），点击可快速跳转，随滚动自动高亮当前区块。

### 1. 概览（命盘核心）
页首大字展示你的**本命卦**，下方标签概括刻别、本命数、先天命数与农历生日。

### 2. 输入信息
回显性别、出生/求测公历时间、农历、是否闰月、两个八字（年月日时四柱）。

### 3. 基础排盘 —— 每个参数都能点
所有参数卡（先天命数、五音命数、日命数、时运数、刻别、本命数、十二辟卦、后天命数、三元九运、终局条文数、五数寄宫、八卦加则）**都可以点击**：点一下，下方会弹出该参数的**白话解释**——不懂命理术语也能看明白它是什么、怎么来的、有什么用。再点一次收起。

### 4. 卦象
显示本命卦的上卦、下卦与五行。

### 5. 本命条文
按「性格 / 才能前程 / 财运 / 兄弟个数」列出条文数与断语，断语下方附**现代白话**。

### 6. 流年推演（1~108 岁）
区块开头有「**三种条文怎么看**」引导框。按 1-30 / 31-60 / 61-90 / 91-108 岁分段切换，每岁一张**卡片**：

- 默认显示：**岁数 / 公历年**（虚岁 1 岁 = 出生当年）、**干支**、**主断语**（取校正后条文断语）。
- **点击展开**：原条文 / 校正后条文 / 铁板公式三组的条文数、断语、现代白话，以及五音 / 标记 / 字母 / 校正数 / 八卦加则标签。「校正后条文」带**主判读**徽标并高亮。

## 三、三种断语看哪个？

| 断语 | 是什么 | 建议 |
|---|---|---|
| 原条文 | 最原始查得的条文断语 | 参考 |
| 校正后条文 | 按年龄校正后的条文断语 | **一般以此为准** |
| 铁板公式 | 原条文数 + 刻干数×48 的断语 | 本系统「终局」口径，作对照 |

> 具体以哪个为主，取决于你所依循的铁板流派判读习惯。

## 四、现代白话

两类白话辅助：

1. **断语白话**：每条文言断语下方的绿色小条，是它的现代白话释义。
2. **术语白话**：基础排盘参数点击可见的解释；完整报告页则在每个参数下直接印一句微注，并附「名词白话对照」表。

白话为辅助参考，原文言仍为准。

## 五、完整报告与打印

结果页底部点「查看完整报告」打开 `Print.html`：所有内容（含 1-108 岁全部流年、每岁三种条文与白话、名词白话对照表）一次性完整展开，点「打印报告」可直接打印或另存 PDF（自动转为 A4 白底版式）。

## 六、常见问题

- **出生分钟不确定？** 刻别按 15 分钟一刻划分，分钟误差可能改变刻别，进而影响刻干数与条文，尽量填准。
- **换了浏览器/清了缓存看不到上次结果？** 结果存于本机 localStorage，换设备或清缓存即丢失，重新排盘即可。
