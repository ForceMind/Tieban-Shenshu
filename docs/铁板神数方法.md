# 铁板神数算法方法说明

> 本文描述**本系统所实现**的铁板神数推演算法，所有公式、取数体系与规则均与代码（`js/tieban.js` / `main.py`）一致，供研习与核对之用。文中「表 14-x」对应 `DB/*.csv`（已导出到 `js/db-data.js`）。
> ⚠ 铁板神数流派众多，本文仅说明本项目采用的一套实现，不代表唯一正解。

## 输入

- **性别**：男 / 女
- **出生时间**（公历，精确到分钟）
- **求测时间**（公历，精确到分钟）

系统先用历法库把两个时间各转为八字（年/月/日/时四柱干支）与农历月日。四柱边界规则：
- 年柱：以农历正月初一为界（非立春）
- 月柱：以节气（节）为界，日粒度
- 日柱：以子时（23:00）为界，晚子时进入次日
- 时柱：按两小时时辰，子时用进位后的日干起五鼠遁

## 一、先天命数（cong_num）

```
先天命数 = 月份表(14-1)[农历月] + 3 − 时辰表(14-2)[出生时支]
若结果 ≤ 0，则 +12
```
闰月时农历月数额外 +1（超过 12 归 1）。先天命数取值 1~12，是后续多张表的检索键。

## 二、五音命数（tone_num）

1. 由出生**年干**定「干组」：甲己 / 乙庚 / 丙辛 / 丁壬 / 戊癸。
2. 以先天命数查表 14-3，在对应干组下得五音（宫/商/角/徵/羽）。
3. 五音查表 14-4 得五音数 `tone_num`（宫5 商4 角3 徵2 羽1）。

## 三、日命数与时运数

- **日命数**：出生**日柱**纳音五行 → 查表 14-5，在**求测时干**下取值。
- **时运数**：**求测时柱**纳音五行 → 查表 14-6 取值。
- 记 `和值 sum_val = 日命数 + 时运数`。

## 四、八刻与刻干数（本系统特色）

一个时辰（2 小时）细分为八刻，每刻 15 分钟，由出生时间的分钟定刻：

| 刻别 | 初刻 | 一刻 | 二刻 | 三刻 | 四刻 | 五刻 | 六刻 | 正刻 |
|---|---|---|---|---|---|---|---|---|
| 分钟 | 0-15 | 15-30 | 30-45 | 45-60 | 60-75 | 75-90 | 90-105 | 105-120 |
| 刻干数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

（子时 23:00-01:00 对应分钟 0-120。）

另有「组别 / 刻别」判定用于查条文：
- 组别：阳男阴女（男且阳年干，或女且阴年干）/ 阴男阳女
- 依「组别 + 和值是否 >6」查规则表得 `Initial（初刻）` 或 `Main（正刻）`

## 五、本命数与终局条文数

```
基数 base_val = 五音数 × 5 + 日命数 + 时运数
因子 fact    = base_val − 1   (和值 ≤ 6)
              base_val − 6   (和值 > 6)
本命数 main_num = fact × 30 + 农历日
```

**铁板核心公式：**
```
终局条文数 = 本命数 + 刻干数 × 48
```

## 六、十二辟卦（卦名）

以（刻别，本命数）查详细卦表，未命中则以本命数查简表，得卦名（如 泰、复、乾…）。卦名用于本命条文检索与八卦加则。

## 七、本命条文

以（卦名，Initial/Main，先天命数）查命数表，得 `base`、`seq` 及各类别（性格 / 才能前程 / 财运 / 兄弟个数）的偏移量。每条：
```
条文数 = base + seq + 偏移
```
再以条文数查断词表得断语（12000 条条文断词库）。

## 八、后天命数与五数寄宫

```
后天命数 pn = (先天命数 + 本命数) mod 8      (为 0 记作 8)
```
若 pn = 5，触发**五数寄宫**：按三元九运与性别阴阳取寄宫卦，再以后天卦数替换。

| 元期 | 年份 | 规则 |
|---|---|---|
| 上元 | 1864-1923 | 男艮 / 女坤 |
| 中元 | 1924-1983 | 阳男阴女用艮 / 阴男阳女用坤 |
| 下元 | 1984-2043 | 男离 / 女兑 |

## 九、八卦加则演变

对（校正后）条文数按卦起始数迭代：
- 起始数：乾 = 36，兑 = 3，其他卦 = 30
- **遇十当不用**：每次相加 ≥10 只取个位
- **变知六八止**：演变到 6 或 8 即停止（最多 10 次）

## 十、流年推演（1~108 岁）

对每个虚岁（1 岁 = 出生当年）：

1. **干支**：由出生年干支顺推。
2. **五音**：由（先天命数，年干/干组）取序列，按流年起始表旋转对齐。
3. **标记**：由当年地支 + 后天命数查标记表（开/石/土/火/水/闭/收/发）。
4. **字母**：由（刻别归并为初刻/正刻，虚岁奇偶，五音，标记）查字母表。
5. **原条文**：由（字母，虚岁）查表得 `base+add`，即原条文数与原始校正数。
6. **校正后条文**：对原始校正数按虚岁施加校正规则后，查校正表得校正后条文数。
7. **铁板公式条文**：`原条文数 + 刻干数 × 48`。
8. 三种条文各自查断词表得断语；再对校正后条文做八卦加则演变。

**条文校正规则：**
```
若 1≤虚岁≤10 或 81≤虚岁≤108：校正数 +2（>6 则 −6）
否则：                        校正数 +3（>20 则 −20）
（原始校正数为 0 则不校正）
```

## 三种断语如何取用

| 断语 | 来源 | 说明 |
|---|---|---|
| 原条文断语 | 字母+虚岁直接查得 | 最原始一层 |
| 校正后条文断语 | 施加年龄校正后查得 | **一般以此为落定条文** |
| 铁板公式断语 | 原条文数 + 刻干数×48 | 本系统「终局」口径 |

三种断语在结果页均附**现代白话**释义（`js/duanyu-modern.js`）。
